# THE OLD EVIL — V19

Base: V18. Rebranding visual, title and English-first localization; languages: English, Español, Deutsch.

## Language
The game opens in English; in pause screen select LANGUAGE on host or phone controller. The choice is synchronized to phone via existing WebSocket session and persists until page reload. No new network requests.

## Visual identity
Painting-inspired deep greens, warm ivory, coral pink and dark-blue retro window accents. Pixel-art title is a PNG rendered on an integer-pixel grid. Existing game sprites and level backgrounds remain unchanged.

## Testing
Run `npm start`, connect via QR, press START and pause to switch language. Camera recognition still requires HTTPS or localhost.
