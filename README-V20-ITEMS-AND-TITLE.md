# THE OLD EVIL — V20

- New large, original, pixelated arcade-inspired THE OLD EVIL title image.
- Every collected item freezes game simulation until A on the phone controller (punch) is pressed.
- Object information contains purpose, controls, and equip directions in EN/ES/DE.
- Frame rendering continues so the item panel remains visible; enemies and projectiles stop.
- Items already collected continue to be stored; queued finds are acknowledged individually.
- Original gameplay, input binding, QR, and inventory retained.
- Keyboard fallback: J or Enter acknowledges the finding.

## Acceptance / verification

- Collecting a dropped item immediately stops the game simulation (including enemies and knives) and displays the existing item discovery overlay, with added contextual instructions.
- Press A on the connected phone to acknowledge and continue; Enter or J is a local keyboard fallback.
- Item guidance is selected from English, Spanish or German translations and names the exact controller buttons and SELECT equipment controls.
- The logo artwork is an original pixelated arcade-style wordmark, tightly cropped to be much larger on the opening screen.
- The game logic and character sprites remain unchanged beyond the pickup interruption.
