# THE OLD EVIL V21 — Dialogs, controller, first start

Built on V20. Gameplay, sprite art, QR, controls mapping, inventory and three languages remain unchanged.

1. Item-found overlay: smaller, translucent panel with a light veil over gameplay; the pause until pressing A remains intact.
2. Paused overlay: reduced opacity. Controller menus: semi-transparent panels and dimmed backdrop.
3. Controller: enlarged face buttons (A/W/D/S), shoulder buttons (L/R/R2), START and SELECT. Joystick geometry and gesture thresholds unchanged. Responsive media queries keep controls usable on smaller devices.
4. On joining a session before START, a multilingual on-phone hint appears and the START button pulses. The hint disappears after gameplay begins and on disconnect. A reconnect to an unstarted game shows it again.

Important: check on the actual smartphone screen as viewport, safe-area insets, and device scaling may differ.
