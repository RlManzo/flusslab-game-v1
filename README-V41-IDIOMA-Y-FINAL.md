# THE OLD EVIL V41 — Configuración de idioma y final de demo

Base: V40. Se conserva el reconocimiento de personajes y objetos de la pintura.

- La confirmación del héroe reproduce el mismo efecto de moneda que la confirmación de objetos.
- Menú de idioma oculto arriba a la izquierda de la pantalla de inicio: aparece al pasar el mouse, permite inglés, español y alemán. El botón de cierre con mouse sigue arriba a la derecha.
- El idioma elegido se mantiene entre partidas y se aplica a la interfaz del juego y al prólogo. El prólogo tiene tres imágenes con texto integrado en cada idioma.
- Al derrotar al jefe final, o alcanzar el límite del mapa exterior con la última oleada superada, se muestra un mensaje de continuación en el idioma elegido durante 20 segundos y después se reinicia la sesión y el QR.
- Se mantiene el reinicio de 15 segundos por muerte.

Verificado: sintaxis JavaScript, estructura de archivos y ZIP. Pendiente probar el flujo completo con Render, Raspberry Pi y celular.
