# COSWIG V17 — Menú de pausa y salida de operador

- El mando del celular muestra PAUSA con CONTINUAR y RESTART solo durante la pausa.
- La pantalla principal ofrece los mismos controles en su menú de pausa.
- RESTART restablece la partida (vidas, enemigos, objetos, escenario) conservando la conexión del mando.
- La esquina superior derecha contiene una X de operador, invisible hasta que se coloca un mouse en los últimos 66×66 px. No se revela por toque ni por joystick.
- Limitación de seguridad de navegadores: una página web no puede garantizar que `window.close()` cierre una pestaña abierta manualmente ni cerrar por sí sola todo Chromium. Si se deniega, se indica al operador Ctrl+W/Alt+F4. Para cerrar una ventana tipo app en una Raspberry Pi, configurá el lanzador del navegador o un servicio local autorizado.
